# タチコマ 音声テスト v0.2

AIエージェント「タチコマ」の音声UIの試作です。ブラウザの標準機能（Web Speech API）だけで動く静的ページで、サーバーもAPIキーも使いません。

- 音声読み上げ：`speechSynthesis`（声・高さ・速さを選べる）
- マイク入力：`SpeechRecognition`（日本語）
- 診断パネル：HTTPS／読み上げ／音声認識／マイク許可／日本語の声の有無
- 会話履歴：画面の中だけ（保存・送信しない）。返事はまだ固定の文で、AIにはつないでいません

## 試し方
1. Mac の Chrome / Safari、iPhone の Safari で公開URLを開く
2. 「🔊 試しに喋らせる」で声が出るか確認
3. 「🎤 押して話す」でマイクを許可し、「こんにちは」などと話す
4. うまくいかないときは「診断」の「結果をコピー」の内容と、画面のスクリーンショットを送る

## 含めないもの
音声サンプルの原本、APIキー、個人情報、Life Game のコード。
